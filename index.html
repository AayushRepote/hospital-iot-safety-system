ℹ️ About Project

Hospital IoT Safety System

An ESP32-based environmental monitoring prototype designed to demonstrate real-time monitoring of temperature, smoke, fire/flame and vibration sensors.

Hardware

  • ESP32
  • DS18B20 Temperature Sensor
  • MQ-2 Smoke Sensor
  • Flame Sensor
  • Vibration Sensor
  • SSD1306 OLED
  • Buzzer

Architecture

Sensors → ESP32 → Wi-Fi → Web Dashboard
